# Project Overview

## Objective

Build and evaluate a movie recommendation model using Microsoft Azure Machine Learning Studio. The model learns patterns from user–movie rating data and produces predicted ratings or recommendation scores.

## Approach

The project uses collaborative filtering with an SVD Recommender component inside Azure ML Designer. The documented workflow covers data preparation, training, scoring, evaluation, model registration, and an attempted online deployment.

## Recorded outcomes

- Pipeline and child jobs: **Completed**, according to the report.
- Evaluation metric: **NDCG = 0.9639892**.
- Model registration: **Version 1**.
- Endpoint: did not reach **Ready** and was removed during cleanup.

## Repository contents

This repository presents the workflow and evidence from the uploaded PDF. It includes the report, extracted screenshots, README architecture diagram, and concise documentation. The PDF does not provide data files, executable source scripts, or the trained model artifact.
